# Gudetama-Macropad
A Gudetama-themed macropad designed using the Hackpad guide. It has 5 keys with a knob that adjusts the volume, an OLED Display, and 4 RGB LEDs.

## Features 
- 5x Keys
- 1x Rotary Encoder
- 1x 0.91" SSD1306 OLED, 128x32
- 4x SK6812 MINI-E rear-mount RGB LEDs
- 1x Transparent Acrylic (62mm x 34mm)
- Gudetama-themed silkscreen + engraved case!

## Key Map
| Type | Action |
| --- | --- |
| SW1 | Copy |
| SW2 | Paste |
| SW3 | Undo |
| SW4 | Redo |
| SW5 | Play/Pause |
| Knob (when pressed) | Mute |
| Knob (turned) | Volume adjusted up and down |

## Hardware
- **Microcontroller**: Seeed XIAO RP2040
- **PCB**: 80 x 115 mm, 2-layer, designed in KiCad
- **Case**: 3D-printed tray and frame, designed in Onshape
- **Transparent Window**: 3 mm clear acrylic (laser-cut)

## Firmware

Written in VS Code using CircuitPython + KMK. AI was used to help write the code.
- code.py - full firmware
- test_keys.py - buttons only to test wiring
